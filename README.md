# 🌌 Sobre o projeto

O **PokéGuess** não é apenas um jogo de adivinhação.

A proposta do projeto foi criar uma experiência:
- visual
- nostálgica
- divertida
- cinematográfica

misturando:
- efeitos neon
- interface estilo Pokédex
- áudio
- feedback visual
- suspense
- acessibilidade infantil

Tudo consumindo dados em tempo real da PokéAPI.
